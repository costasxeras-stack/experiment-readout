Check an A/B test before you trust it.

Load a test result. The readout checks the data first (group split, wrong versions shown, duplicate users, outliers), then the metrics, and gives one of four calls with the reasons: ship, don't ship, run longer, or fix the data first.

One row per user. Columns for the group, and one or more metrics (0/1, true/false or numbers). Optional: user ID, version shown, timestamp.

The file stays in your browser. Nothing is uploaded to a server.
